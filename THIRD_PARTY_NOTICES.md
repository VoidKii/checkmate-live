## Stockfish 18

The Android build downloads the official Stockfish 18 Android engine binaries from:
https://github.com/official-stockfish/Stockfish/releases/tag/sf_18

Stockfish is licensed under GNU GPL version 3. The complete license text is in `Stockfish-COPYING.txt`. Corresponding source code is available from the official Stockfish repository:
https://github.com/official-stockfish/Stockfish/tree/sf_18

The build verifies the downloaded engine binaries against pinned SHA-256 checksums before packaging them.
